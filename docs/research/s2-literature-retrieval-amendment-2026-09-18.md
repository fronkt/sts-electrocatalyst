# P-LIT retrieval amendment — 2026-09-18

This changes the database discovery procedure in the September 18 S2 operating specification after inspecting the first response page of each registered query and before making any paper inclusion decisions or entering any method-reporting codes. The original search specification, all eight first-page responses, request receipts, failures, candidate records and incomplete readout remain preserved under `results/s2_2026-09-18/literature/`. They are an incomplete discovery inventory, never an exhaustive literature census.

The trigger is the documented meaning of Crossref's bibliographic search. Crossref staff state that `query` and `query.bibliographic` require only 20% of the query words to match; these are not conjunctive searches for the complete topic ([Crossref staff clarification, November 18, 2024](https://community.crossref.org/t/advanced-set-boolean-operators/4596/3)). The first-page counts returned on September 18 were:

| Literal query | OpenAlex reported results | Crossref reported results |
| --- | ---: | ---: |
| `rutile oxygen evolution` | 22,256 | 798,461 |
| `RuO2 oxygen evolution` | 6,794 | 794,614 |
| `IrO2 oxygen evolution` | 5,138 | 793,911 |
| `rutile oxide computational hydrogen electrode` | 3,892 | 1,366,230 |

These counts are database matches, not eligible papers. The initial 4,400 returned records produce 2,333 DOI-deduplicated metadata candidates; no inclusion list or hypothesis outcome is inferred from that subset. The Crossref total of 3,753,216 query matches reflects a broad partial-word search and does not implement the intended scoped discovery procedure. Stopping it at the first page would introduce an unregistered top-N selection; this amendment instead changes Crossref's role explicitly.

**Amended discovery procedure.** Exhaust all available pages of the four unchanged literal OpenAlex queries over the unchanged publication window, 2011-01-01 through 2026-09-18 inclusive. Preserve raw responses, dates, query parameters, cursors, failures, total counts and all candidate identities. Resume verified cached OpenAlex pages in a separate amended-run directory, retaining the original inventory. No top-N cutoff or silent date/query narrowing is introduced. Add the registered already-known candidates from Xu 2015, Man 2011, the Divanis ESI source list and both August 15 literature syntheses. Inspect references once from each included paper as already specified; retain discovery provenance and resolve inclusion before coding. There is no recursive or forward-citation expansion in the primary sample.

**Amended Crossref role.** Crossref supplies DOI-specific bibliographic validation for candidates ultimately included in the frozen list, using `/works/{doi}`. Preserve returned title, authors, article type, journal, identifiers, online/print dates, request receipts and conflicts against the source article and OpenAlex. Failed or missing DOI metadata remains unresolved. Broad Crossref query results are preserved as the superseded inventory; they are not substituted as a top-N discovery arm or treated as completed enumeration. DOI metadata validation does not decide whether an article meets the scientific inclusion rule.

All scientific inclusion/exclusion criteria, first-publication/date handling, preprint/journal deduplication, the predicted proportion strictly greater than 0.80, binary reporting definitions, UNKNOWN handling, evidence requirements and independent coding review remain as written in the original specification. This is an operational revision informed by observed retrieval behavior, not a blind unchanged protocol. It does not claim equivalence to exhaustive dual-database discovery. The reduced database coverage and the preserved original incomplete streams must be disclosed beside the eventual candidate/inclusion accounting.

Before any method coding, freeze the complete amended candidate and inclusion/exclusion lists with reasons and unresolved-access entries. No hypothesis verdict is available before discovery, inclusion and coding accounting are complete. Inaccessible material retains UNKNOWN; the registered lower/upper bounds determine whether a verdict is defensible despite those unknowns. OpenAlex enumeration alone does not close the complementary-source/reference discovery or Crossref DOI-validation obligations.

**Pagination integrity.** Report per-stream raw records, unique provider identifiers, duplicate identities, unresolved provider identities and the first/all observed API totals. Unexpected duplicate identities, missing or malformed provider identities, changing totals, repeated pages, failed requests, malformed cached data or missing continuation evidence leave completeness unresolved. Even a repeated terminal page is counted and indexed before stopping. A raw-record hash preserves records without provider identities but never counts as a verified provider identity. Source occurrences remain in the denominator accounting; deduplication never deletes their provenance. Crossref's August 24, 2026 cursor update documents persistent cursors and potentially changing result sets, reinforcing the need to retain count/duplicate checks ([Crossref cursor announcement](https://community.crossref.org/t/changes-to-cursors-filtering-and-sorting-in-the-rest-api/16246)).

**Execution integrity.** An exclusive output-directory lock prevents concurrent writers. A stale lock is inspected before removal; it is never cleared automatically. The pipeline records its source hash at import/start in the run specification, requires that revision on resume, and verifies it again after candidate export. A changed source revision refuses completion while preserving retrieval evidence. Continuing with revised code requires a separately identified run and verified cache transfer, preserving the original specification and receipts.

Commit and push this amendment and its execution code before beginning exhaustive amended discovery.
