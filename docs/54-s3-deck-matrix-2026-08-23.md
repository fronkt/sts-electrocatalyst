## 0. Scope and conventions

**The crossing (A8.1, docs/43:1509-1516):** `tier_v3` = coverage/cell {1×1, 2×1v} ×
symmetry {off-plane (`nosym` + physical displacement), mirror (symmetry ON)} × magnetic
basin {production seed, second seed} over **8 systems**. Interaction reported
NON-ADDITIVE where |E(both) − E(cell) − E(sym) + E(neither)| > 0.10 eV, at fixed basin
(docs/43:1523-1525).

**The 8 systems** = the tier_v2 seven (Cr, Mn, Fe, Co, Ni, Ru, Ir — docs/43:29) **plus
TiO2** (round-2 synthesis:93 "RECOMMENDED: n = 8 ... The existing seven plus TiO2";
S3 job list synthesis:249-252). **Cu is NOT in S3** (CuO2 "does not exist; already
dead", synthesis:118; A5.5 firewall "the Co *OOH and Cu holes remain holes",
docs/43:1114; docs/51:24 SUPERSEDED, Cu PAW not staged on Anvil). **SnO2 is a
conditional 9th only** — gate (i) PASS banked and Mom-2014 cus-site condition CONFIRMED,
but admission "awaits only the entrant's declaration" (docs/45:74, docs/53). This matrix
is 8 systems until that declaration.

**States:** clean slab (`ref`) + *O, *OH, *OOH — "four states including the clean slab",
uniform audit depth (synthesis:259; docs/43:1194-1195).

**Corner code** (interaction accounting per A8.1, per metal-state at fixed basin):
**N** = E(neither) = 1×1 mir · **S** = E(sym) = 1×1 off · **C** = E(cell) = 2×1v mir ·
**B** = E(both) = 2×1v off. Bares are references (`ref`), not corners. For Cr (9 4 1)
and Mn (9 4 1, n1 odd) the 1×1↔2×1v corners require the k-bridge correction
(build_cellsym_pilot.py:941-986; synthesis:252 Mn k-bridge).

**Dispositions:** **BANKED** (converged `bfgs converged` + `JOB DONE` relax reusable for
the cell; A8.8 forbids replacing it, docs/43:1754-1764) · **BUILD** (firm S3 deck) ·
**BUILD-T** (second-seed cell inside the registered basin factor whose activation waits
on the entrant's "wherever triage allows" line, docs/43:1516, :1645; docs/52:191-194) ·
**HOLD** (gate-(h)/Ru-AFM family, docs/43:1645) · **GAP** (registered exclusion or
registered reported-gap) · **OPEN** (readers disagreed or registration silent — §6).

**Basin factor ground rules:** second seed applies only to spin-polarised metals; Ru/Ir
run nspin=1 in production → one deck per cell (LIT-3 reading, **awaiting Frank's
sign-off**, runs/probe/lit3_manifest.json:71); TiO2 is d0 nspin=1 (synthesis:93). The
Cr/Co/Ni basin restarts are **production-seed** fresh-density repairs, not second seeds
(same `starting_magnetization`, build_basin_restarts.py:53-57) — see §6 item 4.
Acceptance rule: lowest configuration adopted only if > 20 meV below runner-up, else
MULTISTABLE with a range (synthesis:361). Pairs differing > 0.05 µB in converged total
magnetisation are CONFOUNDED (docs/43:1566-1571); a `__g1` child > 1 meV above its
parent is refused → re-run from parent density → MULTISTABLE on repeat
(docs/43:1589-1592).

**Paths** in tables are relative to `runs/`. `E` in Ry (final `!`), `M` = total
magnetisation (µB); nspin=1 rows print no M. "synthesis" =
docs/research/2026-08-15-lit-sweep-round2-synthesis.md; "round1" = the round-1
counterpart.

**Convergence-failure protocol (A8.4, docs/43:1596-1604):** ladder = restart from a
converged neighbour's density → halve mixing β → NOT_CONVERGED plotted as a gap; the
failure rate is a reported quantity; > 20% on a state → LOW-CONFIDENCE, never dropped.

`--bind-to core` flagged not decided; PARITY_PASS gate in force (docs/43:1613-1621).
nspin=2 relax cost carries docs/51:25's 2–4× understatement flag (the ~237/270 basis is
the nspin=1 TiO2 gate-(g) deck).

**Naming/directory convention (proposed):** new S3 decks go to
`runs/s3/<Metal>/<state>__<cell>_<arm>[__<seed>].in` — states
`ref|s0_O|s0_OH|s0_OOH`, cells `1x1|2x1v`, arms `off|mir`, seeds: *(none)* =
production, `__magm` = second seed (recipe pending sign-off), `__ns` =
starting_ns_eigenvalue start, `__afm` = Ru AFM (HOLD), children `__g1`, Mn bridge
`__1x1_k8`. Examples: `runs/s3/Mn/s0_OOH__2x1v_off.in`,
`runs/s3/Fe/s0_OOH__2x1v_off__magm.in`, `runs/s3/Ti/ref__2x1v.in`. This follows the
`runs/probe/<Metal>_<family>/` grammar the driver/manifests already parse (4-field
manifest rows, src/dft/queue_r1.sh:5-7) and keeps the banked tree read-only (A8.8; the
Co_slab-in-place trap, docs/51:23). Bare `ref__2x1v` decks run `nosym` at 16 k,
matching the block-1A reference convention (build_cellsym_pilot.py:874-887).
